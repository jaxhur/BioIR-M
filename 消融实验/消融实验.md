# 主组件消融

主组件消融

- M1 不启用 BEPR 和路由辅助损失；
- M2 启用 \(\mathcal L_b,\mathcal L_{\mathrm{scope}},\mathcal L_R\)；
- Ours 再加入监督结构引导发送组件。

| 组别 | 交互模块          | \(A/R\)           | \(D\rightarrow G\) 发送 token | \(\lambda_S\) | 证明什么                     | PSNR | SSIM | LPIPS |
| ---- | ----------------- | ----------------- | ----------------------------- | ------------- | ---------------------------- | ---- | ---- | ----- |
| M0   | 原 BioIR AttBlock | —                 | —                             | —             | 原始 baseline                |      |      |       |
| M1   | SARI              | \(A=0.5,\ R=1\)   | PatchAvg                      | 0             | SARI 整体替换是否有效        |      |      |       |

# SARI双向消息的贡献

这三组只能证明：

- \(G\rightarrow D\) 上下文检索有贡献；
- \(D\rightarrow G\) 可靠细节聚合有贡献；
- 两个方向联合优于单方向。
- 不能严格证明“非对称算子一定优于对称算子”。为了节省时间，不必再训练一个对称双 cross-attention；论文中不要写“实验验证非对称优于对称”，写成“两个方向承担不同职责，单方向消融验证二者均不可缺少”即可。、

两个变体均从头训练，只关闭对应消息写回，其他网络、预测头和损失保持不变

Ours、两个方向消融和参数敏感性中的默认设置都复用同一个配置/结果，不重复训练

最终指标均在裁回原始 \(400\times600\) 后计算，不能直接在补边图上计算

| 变体                   | \(G\rightarrow D\) | \(D\rightarrow G\) | PSNR | SSIM | LPIPS |
| ---------------------- | ------------------ | ------------------ | ---- | ---- | ----- |
| w/o \(G\rightarrow D\) |                    | ✓                  |      |      |       |
| w/o \(D\rightarrow G\) | ✓                  |                    |      |      |       |
| Ours                   | ✓                  | ✓                  |      |      |       |



# 参数敏感性实验

**区域粒度与稀疏聚合比例的联合敏感性**：

- 同时保持：\[ q_g/q_r=4,\qquad k/q_r^2=1/16=6.25\%. \]
- 默认设置在区域粒度、稀疏结构保留和实际推理开销之间取得了更好的综合平衡。

| 设置   | \(q_r\) | \(q_g\) | \(k\) | PSNR | SSIM | LPIPS |
| ------ | ------- | ------- | ----- | ---- | ---- | ----- |
| 细粒度 | 8       | 32      | 4     |      |      |       |
| 默认   | 16      | 64      | 16    |      |      |       |
| 粗粒度 | 32      | 128     | 64    |      |      |       |

推理时，输入LOLv1完整图片（高400、宽600），三组实际补边尺寸分别为：

- 三组训练均使用 $256\times256$ patch，因此训练阶段不产生额外补边。
- 推理时按照各自的 $q_g$ 将 LOL-v1 完整图补到对应尺寸，并在输出后统一裁回原始 $400\times600$ 再计算指标。由于必要补边尺寸随 $q_g$ 同时变化，本实验评价的是区域粒度、稀疏聚合比例及其实际推理补边共同构成的端到端配置，不将性能差异完全归因于单个参数。

| 设置   | \(q_g\) | 实际推理补边尺寸 |
| ------ | ------- | ---------------- |
| 细粒度 | 32      | \(416\times608\) |
| 默认   | 64      | \(448\times640\) |
| 粗粒度 | 128     | \(512\times640\) |


# 已实现配置与运行命令

所有配置只使用 LOL-v1，训练 `PatchSize=256×256`、`BatchSize=4`、
`total_iter=150000`，每 20 iter 打印训练状态、每 1000 iter 在完整 `eval15`
验证。各配置使用不同 `name`，因此自动续训与 checkpoint 目录互不覆盖。

| 实验 | YAML | 关键开关 |
| ---- | ---- | -------- |
| M0 | `options/ablation_m0_lolv1.yml` | `network_g.type=BioIR` |
| M1 | `options/ablation_m1_lolv1.yml` | `routing_mode=constant`，`A=0.5`，`R=1`，`sender_pooling=average` |
| M2 | `options/ablation_m2_lolv1.yml` | `routing_mode=bepr`，`sender_pooling=average`，只含三项路由损失 |
| Ours / 默认粒度 | `options/ablation_ours_lolv1.yml` | `routing_mode=bepr`，`sender_pooling=structure`，`structure_weight=0.05` |
| w/o `G→D` | `options/ablation_wo_g2d_lolv1.yml` | `enable_g_to_d=false`，`enable_d_to_g=true` |
| w/o `D→G` | `options/ablation_wo_d2g_lolv1.yml` | `enable_g_to_d=true`，`enable_d_to_g=false` |
| 细粒度 | `options/sensitivity_fine_lolv1.yml` | `q_r=8`，`q_g=32`，`k=4` |
| 粗粒度 | `options/sensitivity_coarse_lolv1.yml` | `q_r=32`，`q_g=128`，`k=64` |

当前仓库固定采用 C 版，因此 Ours 的“监督结构引导发送组件”只表示预测结构图
参与 `D→G` 发送 token 的加权池化；`refine_with_structure` 保持关闭。M2 到 Ours
只改变发送 token 和 `L_S`，不会额外混入 refinement 结构交叉注意力。

从项目根目录执行：

```bash
sh train.sh options/ablation_m0_lolv1.yml
sh train.sh options/ablation_m1_lolv1.yml
sh train.sh options/ablation_m2_lolv1.yml
sh train.sh options/ablation_ours_lolv1.yml
sh train.sh options/ablation_wo_g2d_lolv1.yml
sh train.sh options/ablation_wo_d2g_lolv1.yml
sh train.sh options/sensitivity_fine_lolv1.yml
sh train.sh options/sensitivity_coarse_lolv1.yml
```

参数敏感性的默认档直接复用 `options/ablation_ours_lolv1.yml` 的训练结果，
不再重复执行一次。验证与测试输出都会先裁回 LOL-v1 原始 `400×600`，再计算
PSNR 与 RGB SSIM；三档 `q_g` 的模型入口补边分别为 `416×608`、`448×640`、
`512×640`。
