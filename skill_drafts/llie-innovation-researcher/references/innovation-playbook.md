## 问题—机制映射

### 亮度不足与照明不均

可借鉴的思想：

- Retinex 光照估计：显式建模大范围照明，而不是对所有区域统一提亮。
- Y/亮度引导：从 RGB 转换或轻量预测得到亮度特征，控制不同区域的修正强度。
- 频域低频/幅度建模：提供全局能量与照明分布，但不能粗暴理解为“幅度等于亮度”。
- 多尺度或大感受野建模：用池化 token、膨胀卷积、方向大核或低分辨率 attention 获得全局上下文。

必须回答：如何避免亮区过曝、暗区提亮不足和块状照明。

### 暗区噪声与模糊

可借鉴的思想：

- SNR/不确定性/可靠性图：估计局部信息是否可信。
- 门控 FFN：让照明或可靠性控制特征通过量，避免暗区噪声被激活放大。
- 噪声感知 skip：浅层纹理只有在可靠区域才回流 decoder。
- 空间—频率选择：平坦暗区偏向平滑与全局分支，可靠边缘偏向局部与高频分支。

必须回答：如何区分“需要保留的高频边缘”和“应该压制的高频噪声”。

### 结构、细节与边缘

可借鉴的思想：

- Sobel、Laplacian、多方向梯度或轻量可学习边缘图。
- FFT 相位、小波 `H/V/D` 子带或 Laplacian pyramid。
- 结构引导交叉注意力：图像特征提供查询，结构特征提供引导。
- 粗增强后细化，但只有在单阶段无法闭环时才引入第二阶段。

必须回答：结构先验是否在极暗区仍可靠，以及如何防止制造假边缘。

### 颜色偏移与亮度—色度耦合

可借鉴的思想：

- YUV/YCbCr/Lab/HSV 中的亮度—色度解耦。
- 轻量色度校正分支或颜色一致性 loss。
- 通道统计、白平衡或色度噪声建模。

单纯换颜色空间不是主创新。颜色机制应回答：亮度增强为什么导致色偏、色度信息如何反馈主干、校正为何不会牺牲自然饱和度。

### 过曝、伪影与局部不连续

可借鉴的思想：

- 有符号残差允许局部提亮与压暗并存。
- 曝光置信度区分暗区、正常区和灯光区。
- 光照平滑与边缘保持联合约束。
- 对高增益区域施加噪声或伪影惩罚。

必须回答：平滑约束如何不跨越真实边缘。

## 全局—局部交互替代库

这些机制可替换动态卷积或普通 concat，但使用前要结合 baseline 和退化问题。

| 机制 | 核心做法 | 复杂度控制 | 适合场景 | 主要风险 |
|---|---|---|---|---|
| 池化 token 交叉注意力 | 全局分支压成少量 token，与局部特征双向 QKV 交互 | token 数远小于 `H×W` | 照明指导局部，局部可靠结构反馈全局 | 若无 LLIE 引导，只是换 attention |
| 通道交叉注意力 | 在通道维计算相关性，把光照特征注入 value | 避免空间 `HW×HW` 矩阵 | 高分辨率 LLIE | 通道语义不清时解释困难 |
| 可靠性门控消息传递 | 用亮度、噪声、结构可靠度控制两路消息 | 卷积 + sigmoid，成本低 | 暗噪与真实细节混杂 | gate 来源或监督不清会退化成普通注意力 |
| FiLM/仿射调制 | 一路预测 scale/shift 调制另一路 | `1×1 Conv` 为主 | 全局照明调制局部响应 | 单向调制可能缺少反馈闭环 |
| 选择性多尺度融合 | 对不同感受野分支预测像素/通道权重 | 限制 2–3 个尺度 | 局部照明不均、结构尺度变化 | 容易与常见 SK/attention 相撞 |
| 低秩双线性交互 | 两路投影到低维后乘法或相关性融合 | 低秩维度小于原通道 | 需要显式二阶交互 | 公式和实现复杂度略高 |

选择交互方式时，优先回答“传什么、由谁控制、为什么此处可靠”，再决定 QKV、门控还是调制。

## 频域使用守则

- FFT 幅度反映各频率分量能量，会影响亮度、对比度和纹理强弱，但不等于纯照明图。
- 相位对结构位置、边缘和内容布局非常重要，但直接修改相位可能带来几何伪影。
- 低频通常包含大尺度照明与颜色趋势，高频同时包含真实细节、噪声和锐化伪影。
- 小波比 FFT 更容易表达局部方向细节，但“小波分解”本身不是创新。
- 任何高频增强都应有结构或噪声可靠性筛选。
- 频域分支应与空间域局部修复形成职责分工，而不是重复做一次卷积。

## 先验使用守则

- 先验应减少网络搜索空间或提供可解释控制，不是为了增加名词。
- 推理时不可获得的先验只能作为训练监督，不能作为网络必要输入。
- 同时使用的显式先验通常不超过 2 个；第三个信息优先由已有特征学习得到。
- 物理先验和可学习特征发生冲突时，应设计置信度融合，而不是无条件相加。

## 贡献组合示例

以下只是结构范式，不能原样当作创新结论：

### 范式 1：照明—细节可靠性闭环

- 模块 A：区域自适应照明/低频校正。
- 模块 B：结构—噪声可靠性细节回流。
- 贡献 C：可靠区域加权结构或曝光监督。

主线：不同区域需要不同增益，而暗区局部高频并不总是可信。

### 范式 2：亮度—色度协同残差

- 模块 A：Y/照明引导的主残差预测。
- 模块 B：轻量色度校正及反向调制。
- 贡献 C：亮度与色度分工一致性约束。

主线：提亮和颜色校正不能独立串联，需要抑制相互干扰。

### 范式 3：频率—空间选择性恢复

- 模块 A：亮度引导的低频/幅度校正。
- 模块 B：结构与噪声筛选的空间/高频修复。
- 贡献 C：中间频带或可靠性监督。

主线：全局照明与局部细节使用不同表示，但必须按区域可靠性融合。

## 常见弱创新与修正方式

| 弱做法 | 为什么弱 | 修正方向 |
|---|---|---|
| baseline + CBAM/SE | 与 LLIE 问题没有专门联系 | 让权重由照明/噪声/结构可靠性产生并改变关键交互 |
| 加 FFT loss | 只改变优化目标，不改变恢复机制 | 在网络中定义频带职责并用 loss 监督对应中间量 |
| RGB 换 YUV | 表示变化常见且计算路径没变 | 设计亮度—色度协同与反馈机制 |
| 加 Sobel 分支 | 边缘图可能同时增强噪声 | 引入暗区可靠性并说明结构图来源与失败情况 |
| 两阶段堆叠 | 参数和故事变重 | 先验证单阶段统一模块能否闭环 |
| QKV 替换动态卷积 | 只是算子替换 | 说明 Q/K/V 分别来自哪种 LLIE 信息及双向消息的物理含义 |
| 堆 5–8 个 loss | 贡献无法归因 | 每个辅助 loss 绑定一个模块和失败模式，限制数量 |

## 除 FFT、下采样和颜色空间外的表达方式

可考虑：

- 小波和 Laplacian pyramid：局部多尺度频带。
- 方向大核/可分离卷积：低成本扩大感受野并保留方向结构。
- 可变形采样：适应结构位置，但要控制复杂度与稳定性。
- 低秩 token 或区域 token：把大范围照明压缩成少量可交互表示。
- 递归/状态空间传播：适合长程依赖，但不要为了 Mamba 名称而使用。
- 隐式坐标或连续照明场：适合建模平滑空间照明，但公式和训练可能更复杂。
- 置信度/不确定性表示：表达“哪些区域、哪些频带值得相信”。
- 多曝光或曲线参数表示：直接预测像素修正规律，而不是任意 RGB 映射。

选择标准仍是：是否直接解决当前主矛盾、能否插入 baseline、是否容易消融、是否与近年工作区分。
