# BioIR 专章：从通用恢复改造成 LLIE 方法

本章只在任务明确涉及 BioIR 时加载。它记录当前代码事实、可论证不足和可探索改造空间；最终方案仍需根据最新代码与论文证据重新核对。

## 当前实现的代码事实

以当前 BioIR-M 项目的 `basicsr/models/archs/BioIR_arch.py` 为例：

- 主干是三尺度 encoder–decoder，并在同尺度使用 `AttBlock`。
- `AttBlock` 由 `AttModule` 和门控 `FeedForward` 组成，二者均有残差连接。
- `AttModule` 先用 `1×1 Conv + 3×3 DWConv` 产生两半通道特征 `x1`、`x2`。
- `L2H(x1, x2)` 对应论文语义中的 P2F：根据一路特征与池化区域的相似性生成逐像素动态核，调制另一路局部特征。
- `H2L(x1, x2)` 对应 F2P：由局部特征生成动态核，反向细化另一支路。
- 两路结果通过逐元素乘法融合，再经 `1×1 Conv` 输出。
- encoder 与 decoder 的 skip 使用 concat 后 `1×1 Conv` 融合，没有显式的低照度可靠性筛选。
- 最终输出为 `output(feature) + inp_img`，已经是残差预测。

重要纠偏：

- 代码中的 `low/high` 是不严谨的变量名，不能直接解释为低频/高频。
- `x1/x2` 只是卷积后按通道一分为二，没有机制先验保证一半天然是全局照明、另一半天然是局部结构。
- P2F/F2P 是外围—中央视觉的双向交互，不是 Fourier 频域模块。
- 残差输出是 baseline 现有机制，不能作为新论文贡献；可以保留并围绕“区域自适应有符号残差”提出更具体的新机制。

## 可论证的 LLIE 不足

下列内容属于基于代码和 LLIE 退化的研究推断，输出时不要伪装成原论文自述：

1. **分支角色隐式**：两半通道的全局/局部职责主要靠训练自发形成，缺少亮度、结构或颜色的明确约束。
2. **动态交互不感知低照度可靠性**：相似度和动态核没有显式区分暗区噪声、可靠边缘与高亮灯光。
3. **局部信息可能污染全局**：暗区高频常含噪声，F2P 若无差别回流，可能把噪声解释为结构。
4. **全局指导不区分区域增益**：P2F 可以传递大范围上下文，但没有直接约束暗区大幅提亮、正常区少提亮和灯光区防过曝。
5. **skip 传播浅层噪声**：浅层细节直接与 decoder 融合，极暗区域的噪声也可能被带回高分辨率输出。
6. **任务身份不足**：原 BioIR 面向通用复合图像恢复；如果仅换数据集和 loss，方法仍不像专门的 LLIE 网络。

这些不足应结合可视化、特征统计或消融验证，不能只靠语言断言。

## 改造优先级

优先保留：

- 三尺度 encoder–decoder 主干。
- AttBlock 外层残差。
- 最终图像残差输出。
- BasicSR 训练和评估框架。

优先重构：

1. L2H/P2F 与 H2L/F2P 的动态卷积交互。
2. 与其配套的分支角色生成或低照度引导。

按证据决定是否再改：

- skip connection 的可靠性融合。
- FFN 的暗区噪声门控。
- 频域、颜色或结构辅助监督。

不要同时把交互、FFN、skip、两阶段、颜色空间和所有 loss 全部换掉，否则无法归因且不再是可控的 BioIR 改造。

## 替换 L2H/H2L 的设计空间

### 方向 A：低秩双向交叉注意力

- 全局支路由亮度/低频/池化 token 提供 `K_g,V_g`，局部支路提供 `Q_l`，完成全局到局部指导。
- 局部支路只从结构可靠区域聚合 `K_l,V_l`，全局支路提供 `Q_g`，完成局部到全局反馈。
- 使用少量区域 token 或通道注意力，避免完整 `HW×HW` 空间注意力。

创新成立的前提：Q/K/V 的来源必须体现照明和结构可靠性，不能只是把动态卷积机械换成普通 attention。

### 方向 B：可靠性门控双向消息传递

- 估计照明/曝光图 `L`、结构强度 `E` 和噪声或可靠性 `C`。
- 全局到局部消息在暗区获得更强照明修正，但在灯光区降低增益。
- 局部到全局消息只允许可靠边缘和纹理通过，暗噪区域降低权重。
- 使用卷积、sigmoid 和逐元素调制，复杂度低于全注意力。

创新成立的前提：可靠性图的来源、监督和双向作用要形成闭环；不能只是再加一个普通空间注意力图。

### 方向 C：频率—空间协同交互

- 一路显式建模低频/幅度和大范围照明。
- 另一路在空间域或小波高频中建模结构细节。
- 由亮度和结构/噪声可靠性共同控制双向融合。

创新成立的前提：明确高频中的噪声筛选；不能把 `x1/x2` 直接重新命名为低频/高频而不做真实分解。

### 方向 D：亮度—色度协同交互

- 亮度支路负责曝光和局部增益。
- 色度支路轻量校正 U/V、Cb/Cr 或可学习色度特征。
- 色度只在可靠区域反馈主干，避免提亮后偏色。

创新成立的前提：存在双向协同或针对性色噪建模；只做 RGB→YUV 转换不够。

## BioIR 推荐贡献包形态

优先尝试以下结构，而不是固定照搬某个名字：

1. **模块 A：区域自适应全局照明交互**
   - 替换或重构 L2H/P2F。
   - 输入为全局/外围特征、局部特征和从低光输入预测的照明/曝光信息。
   - 输出为经过区域增益控制的局部特征。

2. **模块 B：结构—噪声可靠性反馈**
   - 替换或重构 H2L/F2P，或放在关键 skip 上。
   - 只把可信边缘与纹理反馈给全局支路/decoder，压制暗区噪声传播。

3. **贡献 C：与 A/B 绑定的监督或残差策略**
   - 例如照明目标只监督 A，可靠区域加权结构目标只监督 B。
   - 最终仍预测有符号残差，允许提亮暗区并回压灯光/色偏区域。

若颜色是副问题，优先使用轻量颜色约束；若颜色是论文主矛盾，再设计独立的色度协同模块。频域、小波和 YUV 不要同时成为三条平行主线。

## BioIR 端到端检查

详细方案必须写通：

1. `I_low` 如何归一化并生成初始特征。
2. 照明、曝光、结构或可靠性图从哪里产生；推理是否只依赖低光输入。
3. encoder 每个尺度是否共享引导，如何 resize/投影到当前形状。
4. 新模块 A 如何替换 L2H/P2F，输入输出通道是否与 `AttModule` 匹配。
5. 新模块 B 如何替换 H2L/F2P 或控制 skip，是否与 A 重复。
6. 两路如何融合；逐元素乘法是否保留，为什么。
7. decoder/refinement 如何得到残差 `R_hat`。
8. `I_hat = clip(I_low + R_hat, 0, 1)` 如何得到最终图像。
9. 每个中间监督在训练时用什么 GT 构造，推理时是否移除。

## 必做消融

- 原始 BioIR。
- BioIR + 模块 A。
- BioIR + 模块 B。
- BioIR + A + B。
- 完整模型 + 任务约束 C。
- 动态卷积 vs 新交互机制。
- 无可靠性图/固定可靠性/可学习可靠性。
- 新模块放 encoder、decoder、refinement 或 skip 的位置对比。
- 参数量、MACs/FLOPs 和暗区局部裁剪可视化。

额外建议观察：暗墙噪声、灯光过曝、文字边缘、肤色和大面积平坦区域。它们比只看整图 PSNR 更能验证设计动机。
